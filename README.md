Business Sales Performance Analytics
📌 Project Overview
This project was completed as part of the Future Interns – Data Science & Analytics Internship (Task 1).
The objective of this project is to analyze business sales data and create an interactive Power BI dashboard that helps identify revenue trends, customer behavior, product performance, and sales growth.

🎯 Business Objective
Analyze overall sales performance.
Identify top-selling products.
Track monthly revenue trends.
Analyze customer purchasing behavior.
Support data-driven business decisions.

🛠️ Tools Used
Microsoft Power BI
Microsoft Excel / CSV Dataset
Power Query
DAX

📂 Dataset
The dataset contains sales transaction records including:
Customer ID
Invoice Number
Product Description
Quantity
Unit Price
Invoice Date
Revenue

🧹 Data Cleaning
The following preprocessing steps were performed:
Removed duplicate records.
Removed blank values.
Corrected data types.
Created Revenue column.
Formatted date fields.
Verified data consistency.

🔍 Key Insights
Total revenue reached 8.23M.
Over 22K orders were processed.
The business served 4,354 customers.
Revenue increased significantly during September–November.
REGENCY CAKESTAND 3 TIER generated the highest revenue.
A small group of customers contributed a large portion of total sales.

💡 Recommendations
Increase inventory for top-selling products.
Launch promotions during high-performing months.
Reward high-value customers through loyalty programs.
Focus marketing on products with consistently high revenue.
Improve sales strategies for lower-performing products.
